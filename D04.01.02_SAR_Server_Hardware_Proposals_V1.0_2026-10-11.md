## 1. Overview and Purpose

This document outlines proposed hardware configurations for the SAR L1/L2 Ingestion and Persistence Server. 

Unlike downstream AI compute nodes that require massive GPU clusters for deep learning, the ingestion server must excel at high-speed network I/O, concurrent database writes, and 24/7 uptime. Its primary role is to host the Eclipse Mosquitto MQTT broker and the TimescaleDB (PostgreSQL) hypertable, acting as the secure bridge between edge sensors and the overarching research pipeline.

## 2. Configuration Breakdown

### Configuration 1: Enterprise Rackmount Server (Datacenter Scale)
*Designed for massive multi-room deployment, high availability, and long-term cold storage of years of high-frequency telemetry.*

#### Core Components
- **Chassis:** 1U or 2U Rackmount (e.g., Dell PowerEdge R650 / HPE ProLiant DL360 Gen11)
- **Processors:** Dual Intel Xeon Silver or AMD EPYC 8004 Series (16–32 Cores)
- **Memory:** 128 GB to 256 GB ECC DDR5
- **Storage:** 2x 1 TB NVMe M.2 (OS RAID 1) + 8x 4 TB Enterprise U.3 NVMe SSDs (Database Storage)
- **Networking:** Dual 10GbE / 25GbE SFP28 Network Interfaces
- **Power:** Redundant 800W Platinum Hot-Swap PSUs

#### Key Benefits
- **Maximum I/O Throughput:** Enterprise NVMe arrays prevent write-locking during massive concurrent sensor ingestion.
- **Redundancy:** Hardware RAID and dual power supplies ensure zero data loss during localized hardware failures.
- **Scale:** Capable of handling thousands of sensor nodes simultaneously across a campus-wide SAR deployment.

---

### Configuration 2: High-Performance Tower Server (Lab Scale)
*A quiet, standalone server designed for dedicated lab environments lacking formal server rack infrastructure or dedicated datacenter cooling.*

#### Core Components
- **Chassis:** Mid-Tower Server (e.g., Dell PowerEdge T350 or Lenovo ThinkSystem ST250)
- **Processor:** Intel Xeon E-2300 Series (8 Cores)
- **Memory:** 64 GB ECC DDR4
- **Storage:** 1 TB NVMe (OS) + 4x 4 TB SATA Enterprise SSDs (RAID 5 for Time-Series Persistence)
- **Networking:** Quad 1GbE RJ45 Interfaces
- **Power:** Single or Redundant 600W PSUs

#### Key Benefits
- **Acoustic Profile:** Uses larger, slower-spinning fans for whisper-quiet operation in a shared research space.
- **High Capacity, Low Infrastructure:** Delivers enterprise-grade ECC memory and data integrity without requiring rack rails or specialized 220V power circuits.
- **Direct Attach Expansion:** Plenty of internal PCIe slots for adding direct-attach capture cards if needed.

---

### Configuration 3: 1-Liter Micro PC Node (Lab Recommendation & Current Prototype)
*An ultra-compact, low-power node designed for immediate single-room ingestion, edge persistence, and agile protocol development.*

#### Core Components
- **Form Factor:** 1L Micro Desktop (e.g., Dell OptiPlex Micro, Lenovo ThinkCentre Tiny)
- **Processor:** Intel Core i5-10500T (6 Cores, 12 Threads) or AMD equivalent
- **Memory:** 16 GB to 32 GB DDR4 RAM
- **Storage:** 512 GB to 1 TB M.2 NVMe SSD 
- **Networking:** Gigabit Ethernet + Wi-Fi 5/6
- **Power Envelope:** ~10W Idle / ~35W Load (External 65W Brick)

#### Key Benefits
- **Zero-Friction Deployment:** Small enough to mount directly behind a monitor or under a desk inside the SAR envelope.
- **Solid State Reliability:** Single NVMe drive offers more than enough random write speed to ingest Mosquitto payloads into TimescaleDB without bottlenecking single-room architectures.
- **Cost-Effective Prototyping:** Allows the research team to build and validate the complete L1/L2 software stack on physical metal for under $200 before committing to a $10,000 enterprise rack server.
